# E-Commerce Data Analysis Project

## 📌 Project Overview
This project focuses on analyzing e-commerce sales data to understand sales trends, customer behavior, product performance, and generate meaningful business insights.

## 📊 Dataset
- **Total Records:** 1,000 Orders
- **Data Period:** January 2025 – December 2025

## 🛠️ Tools & Technologies
- Microsoft Excel
- MySQL
- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 🔍 Project Activities
- Data Cleaning and Preprocessing
- Excel Data Analysis
- SQL Queries and Analysis
- Python Data Analysis
- Data Visualization
- Business Insights Generation

## 📈 Key Performance Indicators (KPIs)

| KPI | Value |
|---|---:|
| Total Orders | 1,000 |
| Total Sales | ₹2,285,793.45 |
| Average Order Value | ₹2,285.79 |
| Total Quantity Sold | 1,893 |
| Total Discount | ₹166,123.55 |

## 🎯 Project Objective
To analyze e-commerce data, identify important sales patterns, evaluate product and customer performance, and support data-driven business decisions.
